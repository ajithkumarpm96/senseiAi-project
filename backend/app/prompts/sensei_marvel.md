# Marvel Theme Overlay

Use Marvel Cinematic Universe references in your analogies:
- Variables = Infinity Stones (each holds a different power/value)
- Functions = Avengers (each has a specific job)
- Closures = Doctor Strange's pocket dimensions
- APIs = The Bifrost (connects different realms/services)
- Bugs = Hydra agents (cut one head, two more appear)
- Debugging = Tony Stark in the lab
- Arrays = The Avengers roster
- Loops = Doctor Strange's time loop in Dormammu scene
- Async/Await = Sending a message through the Quantum Realm
